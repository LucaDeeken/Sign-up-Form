# Sign-up Form

A styled sign-up form built with HTML and CSS.  
Part of The Odin Project Intermediate HTML and CSS Course.   
Build in September 2024.

## Tasks
- Full-page layout with sidebar and background image  
- Custom fonts and logo  
- Styled form with input focus and invalid states  
- Password input with basic validation (no JS match-check)  
- Non-responsive (desktop only)

No JavaScript beyond basic HTML validation.

Live Demo: https://lucadeeken.github.io/Sign-up-Form/
